# How dany.works is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/dany.works-design)

Last updated: 2026-07-28

## Design character

dany.works is a **studio/personal works site** concentrated on the home experience (seven `/` captures). It should feel like a **crafted studio billboard**: confident type, curated work presence, and a designer’s hand in spacing—closer to a portfolio monograph than a multi-page corporate marketing funnel.

What should survive adaptation:

- Home-first storytelling across multiple viewport crops.
- Curated work presentation with intentional hierarchy.
- Minimal chrome; maximum composition.
- Studio credibility through restraint and typographic confidence.
- Consistency of voice across widths rather than separate “mobile brand.”

## Foundations

### Color

No aggregated role palette retained. Keep a small, intentional set driven by identity and work imagery; avoid inventing multi-token SaaS semantics.

### Typography

Families not declared. Portfolio-scale display plus readable labels; let weight and size create hierarchy.

### Spacing and layout

- Seven home viewports emphasize **responsive home layout** as the core system.
- Sections likely stack as full-width statements; gutters should feel designed, not default Bootstrap.

## Visual language

- Imagery of work is central; UI decoration stays light.
- Prefer crisp alignment and calm surfaces over heavy glass/gradient chrome.
- Motion not established.

## Components and states

### Home hero / intro
Identity + positioning.

### Work modules
Selected projects as composed blocks or media entries.

### Contact / footer
Simple closing pathway without bloated mega-footer patterns unless visually present.

## Responsive behavior

Multiple home widths support a fluid redesign: reflow modules, scale type, maintain studio tone from narrow to wide.

## Practical guidance

**Preserve**

1. Studio portfolio voice.
2. Home-as-system across breakpoints.
3. Work-led visuals.
4. Typographic confidence with quiet chrome.

**Avoid**

1. Generic agency template excess (endless logo walls, stock gradients).
2. App-dashboard patterns.
3. Unsupported font/licence claims.

**Adaptation recipe**

- Strong home identity → selected work blocks → fluid widths → minimal UI.

## Scope note

Seven captures, all `/`. Supported: multi-width home/studio character. Gaps: measured colors/fonts, interior pages, motion.
