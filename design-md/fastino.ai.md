# How fastino.ai is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/fastino.ai-design)

Last updated: 2026-07-28

## Design character

Fastino Labs is a dark, compact AI research/marketing surface. The canvas is near-black (`#0c0608`), type is light, and cards soften with ~20px radii. Blue links (`#0000ee`) appear as classic link color against the dark system. Density is higher than cinematic game sites — card grids and model pages with tight 10–20px gaps.

What should survive adaptation:
- Warm-black canvas `#0c0608` (not pure cold gray)
- White/light type with blue link accent
- ~20px card radius as the default surface language
- 10–20px gap/padding atoms; 40px section tops

## Foundations

### Color

Measured:
- `#0c0608` background
- `#ffffff` text/surfaces
- `#0000ee` link blue

Keep the palette minimal; let model cards and diagrams carry extra hue if needed.

### Typography

Families unsupported. Observed mostly 12–16px UI with weights 300–400; some 13–14/16–20 body. Display exists on heroes but structured samples skew UI-scale.

### Spacing and layout

- Padding 20px ubiquitous
- Gaps 10px (and 4px micro)
- Top padding 40px on sections
- Home + `/models/gliner2` share the dark card system

Radii: 20px dominant; 6–12–30–32 secondary.

## Visual language

Card-heavy, border-separated dark panels, flat surfaces, developer/API taxonomy. Not illustration-first; product/model content leads.

## Components and states

- Simple lab nav
- Hero claim on dark
- Model cards / feature cards at 20px radius
- Model detail page with dense content blocks
- Blue text links

## Practical guidance

**Preserve** warm black, 20px cards, blue links, tight gaps.  
**Avoid** light purple AI clichés and oversized consumer pills.  
**Adaptation** for model labs, research orgs, and API model catalogs.
