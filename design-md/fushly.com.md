# How fushly.com is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/fushly.com-design)

Last updated: 2026-07-28

## Design character

Fushly is a **bright fintech/credits marketplace** for startup perks: white canvas, charcoal ink (`#1a1d23`), and a vivid green accent (`#2dd17f` / `#25b06a`). The system is friendly PLG — huge bold headlines (up to ~72px/700), pill CTAs, soft 12–16px cards, and catalog tiles for cloud/AI credits. Login continues the same green-on-light language with rounded forms.

What should survive adaptation:

- White/light canvas + **green accent** only on actions and key highlights.
- Charcoal primary text `#1a1d23`, not pure black wash.
- Big bold display for value props; 16/24 body.
- Pills (9999) for primary CTAs; 12–16px radii on cards.
- Catalog of credit offers as friendly tiles, not dense tables.

## Foundations

### Color

Measured roles:

| Role | Hex | Use |
|------|-----|-----|
| Accent | `#2dd17f` / `#25b06a` | CTAs, highlights |
| Text primary | `#1a1d23` | Headlines, body |
| Text secondary | `#ffffff` on green / muted gray on light | Button labels / secondary |
| Canvas | `#ffffff` | Page |
| Surface | `#f6f7f8` soft gray | Cards optional |

### Typography

| Role | Size | Weight | LH |
|------|------|--------|-----|
| Body | 16px | 400 | 24px |
| UI emph | 14–18px | 600–700 | 20–28px |
| Display | 72px | 700 | 72px |
| Small | 12px | 400 | 16px |

### Spacing and layout

- Login and marketing often use **48px** padding wells.
- Cards: 12–20px internal padding; 8px gaps between chips.
- Home: hero + logo/proof + credits grid; login: centered form card.

## Visual language

- Friendly radii: cards ~12–16–24px, buttons full pill.
- Green solid fills for primary; outline secondary.
- Soft shadows optional; mostly flat clean fintech.

## Components and states

1. Marketing nav + Get started pill.
2. Hero with large value prop and green CTA.
3. Credits/offer cards grid.
4. Login card — email/social, 12px inputs, green submit.
5. Trust/logo row.

## Responsive behavior

Captures include 1011–2048px widths. Hero type scales down; credits grid drops columns; login becomes single centered column.

## Practical guidance

**Preserve** green accent scarcity, charcoal ink, pill CTAs, big bold claims, soft offer cards.  
**Avoid** dark crypto styling, rainbow badges, tiny dense tables for offers.
