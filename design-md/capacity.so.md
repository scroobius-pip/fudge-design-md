# How capacity.so is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/capacity.so-design)

Last updated: 2026-07-28

## Design character

Capacity markets AI website/MVP building with a **dark, spacious product-site system**: near-black grounds, white primary text, zinc secondary (`#a1a1aa`), soft large radii, and big display type. Pages for clone-website, MVP builder, pricing, and home share the same calm dark chrome so demos and CTAs can pop.

What should survive adaptation:
- Dark marketing default with white type
- Zinc secondary text, not harsh pure gray
- Rounded cards/controls (8–24px)
- Large display (48–60px) with medium body

## Foundations

### Color
Measured: `#ffffff`, `#a1a1aa`, `#fafafa` (light surfaces when used).
Visually dark charcoal/black page background; white headlines; zinc body; occasional blue accent notes in taxonomy—keep accents sparse if used.

### Typography
Weights 300–700. Sizes 10–20 UI, 30–60 display. Lighter weights appear on large display lines; body ~16–18 regular/medium.

### Spacing and layout
6–32 common; section gaps 48–112. Full-width dark bands, centered content, pricing tables/cards, product demo stages.

## Visual language
- Radii **8, 10, 14, 16, 24**
- Gradient backgrounds noted in taxonomy on some surfaces
- Rounded, modern, moderate density
- Dark mode primary

## Components and states
- Primary light-on-dark CTAs
- Pricing plan picker
- Feature explainer sections for AI clone/MVP flows
- Simple marketing nav

## Responsive behavior
Captures ~1232–2048 wide. Dark system holds; sections stack; type scales from 60 toward 36–48.

## Practical guidance
**Preserve** dark zinc-white hierarchy, soft rounding, big calm display.
**Avoid** cluttered light dashboards as the marketing default; don’t over-saturate gradients.

## Scope note
Pages: `/`, `/pricing`, `/mvp-builder`, `/clone-website-ai`.
