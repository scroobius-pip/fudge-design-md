# How emmiwu.com is designed

## Design character

Emmi Wu’s portfolio is airy, gallery-like, and type-forward: large clean sans headlines, generous whitespace, and project imagery as the color story. It reads as contemporary design-personal branding—quiet chrome, strong hierarchy, no template clutter.

## Foundations

### Color

No measured roles; visual:

- **Canvas:** white
- **Text:** black / charcoal
- **Imagery:** full-color project shots and soft gradients inside case visuals
- **UI chrome:** nearly invisible—links and labels stay typographic

### Typography

Observed:

- Display ~48px / ~57.6px line-height, weight 400
- Secondary headlines ~20–24px
- Small labels ~12–15px; some 700 weight for emphasis
- Overall light-to-regular weights with size doing hierarchy

### Spacing and layout

- Padding bands at 12 / 18 / 24px
- Loose vertical composition; projects as stacked or grid case entries
- Wide margins and intentional empty space as a design material

## Visual language

- Minimal header
- Big name or intro statement
- Case study cards or image plates with short captions
- Almost no shadows or ornamental lines

## Components and states

- Wordmark / name lockup
- Text nav (Work, About, etc.)
- Project cover modules
- Footer contact line

## Responsive behavior

Two similar home captures around 926×580. Treat as a single desktop portfolio state; mobile not evidenced.

## Practical guidance

**Preserve**

- White field and oversized calm type
- Project images as the only saturated elements
- 12–24px padding rhythm and lots of air

**Avoid**

- Heavy portfolios with sticky dark navs
- Badge spam, Lottie clutter, or gradient meshes behind type
- Compressing the intro until it feels like a Webflow template

## Scope note

Two home captures only. Guide is primarily visual with light spacing/type measurements; no font families or color roles in structured data.
