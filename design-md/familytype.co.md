# How familytype.co is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/familytype.co-design)

Last updated: 2026-07-28

## Design character

Family Type is a dark, precise type foundry commerce UI. Black surfaces, light gray secondary text, and a mint/neon green (`#05df72`) for prices, checks, and selected borders. Rows and panels use ~14px radii. It feels like a high-end font PDP + configurator: dense information, calm chrome, green only for money and selection.

What should survive adaptation:
- Black foundry UI chassis
- Green `#05df72` strictly for price, success, and selection
- ~14px rounded commercial rows/cards
- Clear split: specimen/marketing vs license configurator

## Foundations

### Color

Measured:
- `#05df72` accent green
- `#fafafa` / `#ffffff` light text/surfaces
- `#a1a1a1` secondary gray

Black canvas dominates configurator screenshots.

### Typography

Families unsupported (ironically). Observed UI:
- 12–16px dominant
- 14/20 secondary
- Weight 400–500
- Display specimens on marketing home are visually much larger

### Spacing and layout

- Horizontal padding 16px very common
- Vertical padding 8 / 24 / 96px bands
- Gaps 32px in larger stacks
- Configurator: left font picker list, right license/pricing column

Radii: 14px dominant; 8–20px secondary; occasional full pills.

## Visual language

Border-separated dark panels, green focus rings on selected license rows, checklist marks in green. Taxonomy: creative/design, monochrome + accent, flat surfaces, large type on marketing.

## Components and states

- Pill nav (Typefaces / Case Studies / Info)
- Font family commerce rows with price
- Selected state = green border + green total
- Dropdown pricing factors
- BUY NOW dark pill
- Home marketing with large type specimens

## Practical guidance

**Preserve** black + gray + `#05df72` selection/price language and 14px rows.  
**Avoid** multicolored ecommerce badges and light-mode defaulting the configurator.  
**Adaptation** for foundries, digital goods PDPs, and license builders.

## Scope note

Eight captures: home + Universal Sans typeface commerce. Colors measured; declared font families for UI chrome unsupported.
