# How a16z.com is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/a16z.com-design)

Last updated: 2026-07-28

## Design character

a16z.com opens like a **dark, confident manifesto**. The home system is cinematic and spare: near-black ground, large display headlines, cool gray secondary type, and just enough gold/blue accent to feel institutional without looking like a consumer SaaS gradient site. Photography and filmic stills carry emotion; UI chrome stays almost invisible.

What should survive adaptation:
- Dark full-bleed canvas
- Oversized, high-stakes headlines
- Cool gray secondary text (`#8998ab` family)
- Minimal nav and quiet footers so content and media dominate

## Foundations

### Color

Measured:
- Accent / link blue: `#0000ee` (classic link blue appears in roles; use sparingly in product adaptations)
- White: `#ffffff` for primary light text and logos
- Cool secondary: `#8998ab`
- Page ground: black / near-black
- Gold/warm highlights appear in taxonomy/visual reading on some modules — treat as optional accent, not a rainbow system

### Typography

Declared families not captured.
- Display ~**48px / ~63px**, weight 700
- Body-ish lines **15–20px**; some tight 13–17px UI
- Medium labels **16px** weight 500 with generous line-height in places (up to ~40px for airy statements)
- Bold 16px for emphasis rows

The voice is editorial-tech: big claim, short supporting line, then proof modules.

### Spacing and layout

- Large section padding (~**40–50px** blocks; side insets ~**40–58px**)
- Content often centered with generous margins (~144px side margins observed on some frames)
- Pill radii up to **999** for chips/buttons
- Vertical stacking of manifesto blocks and story/media rows

## Visual language

- Film stills / photography full-bleed or large cards
- Sparse hairlines rather than heavy card borders
- Gold/gray limited palette with black field
- Buttons as pills or simple rectangles in white/outline

## Components and states

1. Slim top nav on dark ground  
2. Hero manifesto (display line + subcopy + CTA)  
3. Story/media modules  
4. Footer link columns in muted gray  

Default resting frames dominate; do not invent elaborate hover theater.

## Responsive behavior

Three home captures at desktop width. Keep the dark manifesto intact on smaller screens by stacking media under type and reducing display size before adding light-mode templates.

## Practical guidance

**Preserve:** black field, cool gray type, huge claims, media-led proof.  
**Avoid:** bright startup pastels, dense blog sidebars, generic blue-gradient hero kits.

## Scope note

Three captures, all `/`. Colors and type sizes measured; family names and true multi-breakpoint behavior not fully available.
