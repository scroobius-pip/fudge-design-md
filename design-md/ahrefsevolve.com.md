# How ahrefsevolve.com is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/ahrefsevolve.com-design)

Last updated: 2026-07-28

## Design character

Ahrefs Evolve is an **event microsite** that borrows Ahrefs’ orange energy but stages it like a conference trailer: black ground, oversized white “evolve” wordmarks, live stage photography, and pill CTAs. Location chips (San Diego / Singapore) and date stacks sit in a poster composition. It is louder and more editorial than the main product pricing page—built for tickets and lineup, not SEO tables.

What should survive:

- Black event field + orange pills and badges.
- Giant condensed/italic-feeling display wordmarks.
- Real stage photography with audience scale.
- Simple ticket CTA and speaker storytelling sections.

## Foundations

### Color

- **Ground**: black.
- **Type**: white primary; orange for CTAs, location pill (active), and “SINGAPORE”-style badges.
- **Photo**: full-color stage lighting (blues/ambers) supplying atmosphere.
- Logo uses the standard ahrefs orange wordmark.

### Typography

- Massive display for “evolve” (very large, tight, graphic).
- Section heads ~32–48px white sans.
- Body ~16–24px on black.
- Some ultra-light or thin weights appear on oversized type (weight ~163 observed on display samples—treat as very light display cutting).
- UI labels 16px.

### Spacing and layout

- Poster hero with type over/around photo; content sections on black below.
- Radii ~32px on large pills; near-circular on some chips.
- Spacing 8–32px locally; 64–96px section breathing.

## Visual language

- Conference photography, big type overlays, orange capsule buttons (“VIEW TICKET OPTIONS”).
- Location toggle chips top-right.
- Minimal cards—more poster than dashboard.

## Components and states

1. **Event nav** — ahrefs mark, city chips, optional ticket control.
2. **Poster hero** — photo + giant evolve type + deck + date/venue + orange CTA.
3. **Speaker / lineup sections** — large heads, supporting paragraphs (“Full lineup coming soon”).
4. **Ticket CTA** — orange pill with arrow.

## Responsive behavior

Singapore path captured at wide and tall/narrow sizes (including long scroll ~3714px). Hero remains poster-like; type scales down on narrower widths while black+orange system holds.

## Practical guidance

**Preserve** black stage drama, orange capsules, giant event type.  
**Avoid** recycling the blue pricing layout here—this property is cinematic, not tabular.  
**Adapt** multi-city events with chip toggles and a single strong ticket action.

## Scope note

Eight captures mostly on `/singapore/` plus home. Font families undeclared; orange/black system from screenshots and shared Ahrefs brand cues.
