# How abcdinamo.com is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/abcdinamo.com-design)

Last updated: 2026-07-28

## Design character

Dinamo’s site is a **type foundry storefront** that refuses generic marketing chrome. Black, white, and a sharp purple accent (`#6e32e1`) frame enormous specimen type. Navigation is utilitarian; the font is the spectacle. Hardware and news surfaces keep the same blunt, design-studio confidence.

What should survive adaptation:
- Black/white primary polarity
- Purple as a rare, decisive accent
- Specimen-first heroes
- Studio-direct tone — no soft startup illustration language

## Foundations

### Color

Measured:
- Accent purple: `#6e32e1`
- Black: `#000000`
- Gray: `#a0a0a0`
- White grounds and ink inversions as needed for specimen stages

### Typography

The product fonts *are* the display system; UI chrome stays smaller.
- UI and body observations include ~**17px** and smaller labels; display specimens jump to **67–84px+** and far beyond in stage views
- Weights often 400 in captured UI; specimens supply the drama through cut and size
- Family names for UI were not cleanly declared in the capture set — do not invent a UI font license

### Spacing and layout

- Tight optical spacing around specimens; some negative margins for flush type
- Padding clusters ~**5–17px** on compact UI; larger stage margins on home
- Occasional large radius (~**127px**) on specific circular/pill motifs — not a global soft-card system
- Product pages (e.g. buy flows) stay stark and catalog-like

## Visual language

- Full-bleed or oversized lettering
- Minimal hairline UI
- Purple used for links, price moments, or key actions
- Photography only when the story needs hardware/objects; type usually replaces image

## Components and states

1. Top nav (catalog, custom, account/cart)  
2. Specimen hero stage  
3. Catalog lists / family cards  
4. Buy / trial panels  
5. News list with studio photography  

Normal resting state; selection and purchase CTAs should stay blunt and readable.

## Responsive behavior

Home, news, hardware, and buy routes across multiple widths (including narrower news frames). Collapse nav before destroying specimen scale; allow type to reflow dramatically.

## Practical guidance

**Preserve:** black/white, purple accent, specimen as hero, blunt studio UI.  
**Avoid:** pastel marketing kits, stock gradients, or burying glyphs under illustration.
