# How artstation.com is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/artstation.com-design)

Last updated: 2026-07-28

## Design character

ArtStation is a **dark creative marketplace shell** built to disappear behind artwork. Near-black headers, compact icon nav, and dense image carousels/grids mean the UI is a stagehand: small type (~14px), minimal labels, and high-contrast controls (blue Upgrade pill) against a charcoal frame.

What should survive adaptation:

- Dark chrome so full-color art is uninterrupted.
- Horizontal channel/promo carousels with rich thumbnails.
- Compact top bar: explore/learn/shop + search + utility icons.
- Small body type and tight meta; images do the talking.

## Foundations

### Color

No measured roles. Visually black/charcoal surfaces, white/light gray text, blue Pro upgrade accent, multicolor art content. Keep brand accents minimal.

### Typography

Sans ~14px body with ~25px line-height on profile. Hierarchy mostly via weight and image captions rather than large display type on browse surfaces.

### Spacing and layout

Dense. Channel strip is a continuous horizontal media rail under a slim header. Profiles use masonry/grid artwork tiles with thin gaps.

## Visual language

- Dark fills, subtle separators.
- Soft rounded promo cards in the hero rail.
- Icons monochrome until selected.

## Components and states

- Global dark header with search.
- Upgrade/Pro pill CTA.
- Channel chips (Illustration, Character Design, etc.).
- Artwork tiles with hover affordances (not fully detailed in stills).
- Profile header with avatar and meta.

## Responsive behavior

One wide channels strip and one profile crop; mobile not established.

## Practical guidance

**Preserve:** dark stage for art, carousel discovery, compact utilities.

**Avoid:** light-mode default that washes out portfolio drama; oversized marketing type on browse pages.

## Scope note

Only two captures (channels strip + profile) with thin structured tokens. Guide relies on visual inspection.
