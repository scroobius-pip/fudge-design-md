# How 21st.dev is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/21st.dev-design)

Last updated: 2026-07-28

## Design character

21st.dev is a **dark-mode component marketplace** for builders. The shell is charcoal and black, previews are bright, and a mint accent (`#99ffe4`) marks focus, links, and product energy. Density is high: sidebar taxonomies, search, and multi-column preview grids. It feels like a design-tool IDE crossed with a gallery.

What should survive adaptation:
- Dark app chrome with luminous component previews
- Mint as a rare, sharp accent — not a pastel wash
- Dense left navigation + main grid
- Small, highly legible UI type (12–14px core)

## Foundations

### Color

Measured:
- Light text / fills: `#f4f4f5`, `#ffffff`
- Muted text: `#878787`
- Accent: `#99ffe4` (mint)
- Surfaces: near-black sidebars and page ground; cards alternate dark and light preview canvases

### Typography

No declared family in captures; reads as a neutral product sans.
- Core UI **12–14px** (weights 400–500), line-heights ~15–22px
- Titles ~**15–20px** weight 600
- Dense meta at **11–12px**
- Body in marketing moments **16px / 24px**

### Spacing and layout

- Control padding **8–20px**; section pads up to **32–64px**
- Radii **3–12px** (tight product corners, not big consumer pills)
- Featured grids: multi-column cards with consistent gutters
- Left rail categories with counts; sticky tool chrome

## Visual language

- Rounded-rect preview cards, thin separators
- Soft elevation on dark cards rather than heavy drop shadows
- Preview content may be light or dark — the shell stays dark
- Icons are simple monoline glyphs in the rail

## Components and states

1. **App header** — logo, primary nav (Components, etc.), utility actions  
2. **Left taxonomy rail** — Featured/Newest + long category list with counts  
3. **Component cards** — live preview thumbnail, title/meta  
4. **Studio / detail** frames for single components  
5. Search field with compact height  

Active rail item uses a subtle filled state; mint appears on accents and highlights.

## Responsive behavior

Home and community routes captured around 1419–1712px. The system is desktop-app-like; on smaller widths collapse the left rail before destroying the multi-column preview grid.

## Practical guidance

**Preserve:** dark shell, mint sparingly, dense catalog grid, compact type.  
**Avoid:** light-beige marketing redesign, oversized display heroes on every page, rainbow tags.

## Scope note

Six captures across `/home`, community featured/layouts, a studio page, and a component detail. Colors, radii, and type sizes measured; font family names unavailable.
