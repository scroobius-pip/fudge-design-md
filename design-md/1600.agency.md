# How 1600.agency is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/1600.agency-design)

Last updated: 2026-07-28

## Design character

1600.agency presents a **motion studio portfolio** with cinematic restraint. The shell is dark, the work is bright, and UI type stays calm so showreels and stills can lead. It feels like a screening room: low ambient chrome, large media, soft corners.

What should survive adaptation:
- Dark ambient canvas behind luminous work
- Large rounded media stages
- Light, medium-weight sans for labels — never louder than the reel
- Generous vertical pacing between case blocks

## Foundations

### Color

Measured multi-role hexes were sparse. Visually:
- Page ground: deep black / charcoal
- Type: white to light gray
- Media carries full-color photography and motion frames
- Occasional soft gray panels and hairline dividers

### Typography

Family names not declared in captures. Observed scale:
- Display / section claims ~**66px** and **32px** (weights 300–400) — airy, not ultra-black
- Body **14–16px** with ~1.4–1.6 line-height
- UI labels **14–17px**, weights 500–600
- Occasional **20–24px** mid-heads

The type is elegant and light; heavy bold marketing stacks would break the tone.

### Spacing and layout

- Large vertical section gaps; padding clusters around **20–60px**
- Side inset keeps content from the viewport edge
- Radii are a signature: **10–17px** on cards, **24–60px** on larger media wells and pills

## Visual language

- Soft-rounded rectangles for video and project covers
- Minimal borders; atmosphere from darkness + glow of media
- Horizontal project strips and full-bleed showreel moments
- Navigation reduced to a few words

## Components and states

1. Slim top nav on dark ground  
2. Hero showreel / featured still  
3. Project cards with rounded media + short caption  
4. About/contact strips with light sans copy  

Default resting state dominates; motion is implied by the medium, not by chrome animation details in stills.

## Responsive behavior

Multiple `/en/` captures at desktop widths. Treat as desktop-first cinematic layout; stack project cards and reduce radius slightly on small screens rather than inventing a different brand.

## Practical guidance

**Preserve:** dark room, rounded media, light type, work-first hierarchy.  
**Avoid:** bright white marketing templates, sharp 2px enterprise cards, rainbow gradients in the chrome.

## Scope note

Six captures, all English home (`/en/`). Color role extraction was thin; radii, type sizes, and visual reading of the dark portfolio frame drive the guide.
