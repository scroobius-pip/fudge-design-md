# How c82.net is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/c82.net-design)

Last updated: 2026-07-28

## Design character

c82.net’s Naturalist’s Library is a **scholarly, illustration-first archive**. Pages feel like a carefully set natural history volume translated to the screen: serif reading text, moss green and burnt orange accents, square corners, and specimen art as the hero—not UI chrome.

What should survive adaptation:
- Archive/editorial tone over product marketing
- Serif-forward reading experience (~22px body)
- Dual accent pair: **moss green `#73976a`** and **burnt orange `#dd6523`**
- Illustration plates given museum-like space

## Foundations

### Color
Measured roles (varies by section/theme):
- Accent: `#73976a` (green) or `#dd6523` (orange) depending on context
- Text primary: `#000000` on light surfaces; `#ffffff` on dark header/hero bands
- Text secondary swaps between black and orange
Visually: cream/paper or white content grounds, dark charcoal bands for titles, green for interactive/navigation accents, orange for secondary emphasis and some headings.

### Typography
Family undeclared but taxonomy notes **serif** and single-family system. Observed:
- Dominant body **22px** with ~35.2px line-height (1.6) — generous reading
- Display/titles ~67–84px weight **700**
- Secondary ~19.8–34px
- Small UI ~14px
Most running text sits at weight 400; bold reserved for titles.

### Spacing and layout
Spacing observations include ~11–55px steps plus optical values around 33/44. Layout:
- Content index grids for the library
- Specimen pages with large illustration + caption/metadata
- Clear header band, then calm reading column
Hard offset shadows (~11px x/y, no blur) appear frequently — a crisp “lifted plate” effect rather than soft material shadow.

## Visual language
- **Square corners** (no soft app radii)
- 1–2px solid borders common
- Hard drop offsets instead of blurred shadows
- Flat surfaces; illustration provides texture
- Light mode overall with occasional inverted header/hero

## Components and states
- Library index cards/plates
- Illustration detail view with caption stack
- Textual metadata blocks
- Simple archival navigation
States are mostly static populated content; no app-like empty/loading patterns in scope.

## Responsive behavior
Captures are section crops around 1645–1712 wide. Multi-breakpoint rules not firmly established; illustration pages should keep the plate dominant and let text reflow under/aside.

## Practical guidance
**Preserve**
- Serif reading size ~22/35
- Green + orange accent pairing
- Square, archival geometry
- Hard offset shadows for plates if elevating media
- Museum pacing — don’t rush content

**Avoid**
- Generic SaaS blue/purple
- Over-rounded cards
- Tiny 14px body for long natural-history text
- Neon accents that fight the specimen art

## Scope note
Studied Naturalist’s Library index and an illustration detail (`/naturalists-library`, `/naturalists-library/illustrations/2-5-lizars`). Site-wide patterns beyond this project may differ.
