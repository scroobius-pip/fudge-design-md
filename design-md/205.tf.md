# How 205.tf is designed

[Open the live Fudge conversation](https://design.withfudge.com/share/205.tf-design)

Last updated: 2026-07-28

## Design character

205TF is a **type foundry workbench**. The interface is pale, precise, and almost scientific: a large glyph stage, a metrics panel, and a dense character grid. Personality lives in the typefaces themselves; the chrome is disciplined monochrome with one hot action color.

What should survive adaptation:
- Light gray laboratory canvas
- Black specimen as the hero object
- Tabular glyph grids with hairline cells
- A single high-energy CTA (red) for try/buy

## Foundations

### Color

Structured palette rows were empty; visual system reads as:
- Canvas: light gray (`~#e8e8e8`–`#f2f2f2`)
- Panels: white
- Ink: black glyphs and UI text
- Accent action: saturated red floating “Try or Buy”
- Rules: thin mid-gray grid lines

### Typography

UI chrome is small and neutral (**~12–17px**); the specimen can jump to enormous sizes (including multi-hundred-px display). Weights in UI stay regular. The product *is* the font, so UI type must never compete.

### Spacing and layout

- Split layout: metrics/preview left or primary stage + full glyph matrix
- Tight grid gutters inside the character table
- Sparse outer padding; the grid may run wide on large viewports
- Header is a thin utility bar (Typefaces, Designers, Articles, EULA, cart)

## Visual language

- Hairline grid, not chunky cards
- Selected glyph highlighted with a pale cell fill
- Floating rectangular primary button in brand red, bottom-right in the exposure view
- Almost no shadow; flat precision

## Components and states

1. Utility header + cart  
2. Style/metrics panel with labeled guides (ascender, cap height, x-height, baseline, descender)  
3. Glyph matrix with section labels (e.g. Latin-1 Supplement)  
4. Persistent try/buy affordance  

Selection state on the matrix is the main interactive cue visible in stills.

## Responsive behavior

About and exposure pages captured at different widths (including very wide exposure). The grid densifies horizontally on large screens; keep the metrics panel readable before collapsing it under the specimen on narrow views.

## Practical guidance

**Preserve:** lab-gray field, black type as hero, grid precision, one red action.  
**Avoid:** decorating the foundry chrome with gradients, soft marketing illustrations, or multi-colored nav.

## Scope note

Three captures: `/exposure` and `/about` (two widths). Guide combines measured type sizes with visual reading of the exposure workbench.
